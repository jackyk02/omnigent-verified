# codify-ui-sdk

Terminal UI components (Rich + prompt_toolkit) for building
[codify](https://github.com/codify-ai/codify) frontends.

`codify-ui-sdk` provides the reusable rendering and input building blocks used
by the codify CLI to display streaming agent output in the terminal. It is
released in lockstep with the core `codify` package at a matching version:

```bash
pip install codify-ui-sdk
```

See the [codify repository](https://github.com/codify-ai/codify) for full
documentation.
